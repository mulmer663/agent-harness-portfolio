# 04. 따라 만들기 — 혼자 시작한다면

이 하네스는 한 번에 설계한 것이 아니라, 실수가 날 때마다 하나씩 붙여 다섯 달 동안 자랐습니다.
아래는 그 순서를 돌아보고, 혼자 다시 시작한다면 이 순서로 만들겠다고 정리한 것입니다. 각 단계의 실제 날짜는 [부록 A §6](appendix-a-origin.md#6-그-뒤--강연-너머로)에 있습니다.

## 1. 시작 순서

| 단계 | 만드는 것 | 언제 다음으로 넘어가나 |
|---|---|---|
| 1 | 저장소 CLAUDE.md 하나. 자주 쓰는 명령, 문서 지도, "건드리면 안 되는 것"만 적습니다 | 바로 2로 |
| 2 | 역할 셋(planner·tester·reviewer)과 `/feature`·`/review-mine` 커맨드. reviewer에게서 편집 도구를 뺍니다([예시](../examples/agents/reviewer.md)) | 에이전트가 같은 실수를 두 번 할 때 |
| 3 | 작업 노트. 세션이 끝날 때 "왜 그렇게 정했나"를 한 장씩 남기고 바로 커밋합니다 | 노트가 쌓여 손으로 찾기 어려울 때 |
| 4 | 규칙 노트로 승격. 두 번 겪은 실수는 `kind`·`check`·`hits` 를 단 노트로 올리고, CLAUDE.md에는 결론 한 줄만 둡니다([예시](../examples/knowledge/캐시-복원-통과는-테스트를-돌린-것이-아니다.md)) | 노트가 수백 건을 넘을 때 |
| 5 | 로컬 검색(RAG). 작업 전에 비슷한 노트를 찾아 읽게 합니다 | 규칙이 있는데도 지켜지지 않을 때 |
| 6 | 세션 감사. 세션 기록을 읽어 규칙 위반 후보를 매일 셉니다. 판정은 사람이 합니다 | 같은 위반이 계속 쌓일 때 |
| 7 | 게이트. 발생 기록이 많은 규칙부터 PreToolUse 훅으로 막습니다. 판정할 수 없으면 통과시키고 사유를 남깁니다([예시](../examples/hooks/review_gate.py)) | — |

순서를 이렇게 잡은 이유는 두 가지입니다.
- 게이트를 먼저 만들면 무엇을 막아야 하는지 모릅니다. 막을 대상은 감사에서 센 발생 횟수가 정해 줍니다.
- 규칙을 CLAUDE.md에 계속 덧붙이면 길어져서 넘겨 읽힙니다. 노트로 빼고 한 줄만 남기는 단계가 일찍 있어야 합니다.

## 2. 건너뛰어도 되는 것

| 장치 | 필요해지는 때 |
|---|---|
| 동시 빌드 상한과 원격 VM | 한 머신에서 세션을 여러 개 동시에 돌려 메모리가 부족해질 때. 세션이 한두 개면 필요 없습니다 |
| 야간 요약 | 노트가 하루에 여러 건씩 쌓일 때 |
| 주간 LLM 감사 | 결정적 검출(정규식·기록 파싱)로 못 잡는 습관 위반이 보일 때 |
| 용어 사전과 검사기 | 노트에 정의 없는 은어가 퍼져 새 세션이 읽기 어려워질 때 |
| 아키텍처 불변식 문서 | 구조 규칙이 생겼는데 테스트로 다 잠그지 못할 때 |

## 3. 환경

| 항목 | 이 하네스가 돈 환경 |
|---|---|
| 에이전트 | Claude Code (서브에이전트, PreToolUse 훅, 슬래시 커맨드, MCP) |
| 머신 | macOS, Apple Silicon 10코어, 메모리 24 GB |
| 동시 세션 | 많을 때 10개 안팎 |
| 노트 저장소 | Obsidian vault(마크다운) + git |
| 임베딩 | EmbeddingGemma 300M(4비트), MLX 런타임 |
| 벡터 DB | LanceDB(파일 기반) |
| 야간 요약 모델 | Gemma 3n E4B(4비트), 로컬 실행 |
| 검색 연결 | 상시 데몬 하나로 띄운 MCP 서버(`search_wiki`·`read_wiki_note`) |
| 원격 테스트 VM | 메모리 8 GB, 동시 1개(선택) |
| CI | 병합 요청마다 범위 판정과 검증이 돌고, 통합 테스트는 정기·수동 실행 |

에이전트 요금제와 토큰 비용, 하네스를 만드는 데 든 시간은 따로 재지 않았습니다. 그래서 여기에 숫자를 적지 않았습니다.

## 4. 옮길 때 바꿔야 하는 것

- 셸 명령은 macOS 기준입니다. sed 같은 도구는 GNU와 옵션이 다릅니다.
- 게이트가 읽는 세션 기록 형식은 에이전트 도구의 버전에 따라 바뀔 수 있습니다. 훅을 붙인 뒤에는 실제 세션에서 한 번 막히는지 확인합니다.
- 통합 브랜치 이름, 빌드 도구, 테스트 명령은 저장소마다 다릅니다.
